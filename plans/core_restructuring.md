# Архитектура проекта

## Направление зависимостей (Dependency Flow)

Зависимости имеют вес и падают строго вниз:
`features/` -> `lib/` -> `core/`

1. **`src/core/` (Autonomous Primitives)**
   - Чистые автономные расширения без импортов кода проекта. Zero cross-imports.

2. **`src/lib/` (Domain Subsystems)**
   - Чистая бизнес-логика (маршрутизация, токенизация, сборка контекста).

3. **`src/features/` (Feature Slices)**
   - Самодостаточные функциональные модули (`telegram_bot`, `discord_bot`, `admin_panel`).
   - Каждая фича инкапсулирует свою работу с внешним миром и UI/протоколами.
